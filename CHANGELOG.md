# История изменений

## 0.1.0

- Добавлен TUI-плагин для OpenCode 2.2.5 с экспортом `opencode-attention-plus/tui`
- Добавлены сигналы вопросов, разрешений, завершения и ошибок с настраиваемой задержкой
- Добавлены ожидание дочерних сессий, подавление дублей и отмена устаревших уведомлений
- Добавлен нативный канал macOS с явным включением через `nativeNotifications` и проверкой фокуса приложения
- Звук оставлен под управлением штатных настроек OpenCode
- Обеспечено сохранение уведомлений о запросах потомков при новом запуске родителя
- Добавлены проверки планировщика, нативного канала и установки упакованного плагина
