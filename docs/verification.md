# Проверки и покрытие

Проверенная версия OpenCode: 2.2.5. Автоматические проверки не требуют доступа к macOS-уведомлениям; физическая доставка проверяется отдельно

## Автоматические проверки

```sh
npm test
npm run typecheck
npm run build
ATTENTION_PACK_TEST=1 npm test
```

Зафиксированный результат для кода 0.1.0: 64 теста прошли без пропусков при включённой проверке упаковки; проверка типов и сборка прошли. Обычный `npm test` пропускает тест упаковки

Покрыты задержка на границе 1999/2000 мс, вопросы и разрешения, быстрые ответы, отмены, дубли, дочерние сессии и внуки, ошибки, прерывания, повторные запуски, независимые корни и выгрузка плагина. Проверка архива устанавливает пакет отдельно, импортирует публичный `/tui` с настоящим SDK и проверяет подключение и снятие обработчиков

В тестах macOS системные вызовы заменены: проверяются фокус, независимость звука, явное разрешение баннеров, передача данных в JXA, таймаут и отмена процесса. Эти тесты не отправляют реальные баннеры

## Живые проверки

«Проверено» означает наблюдение соответствующего сценария, а не гарантию всех сочетаний настроек и окружений. Результаты относятся к macOS и PyCharm

| Сценарий | Результат |
| --- | --- |
| Загрузка установленного архива в TUI, штатный обработчик отключён | Проверено |
| Вопрос, разрешение, обычное завершение и ошибка корня в фоне | Баннер и звук наблюдались |
| Активное приложение с TUI | Звук без баннера наблюдался |
| `nativeNotifications: false` в фоне | Звук без нативного баннера наблюдался |
| Быстрый ответ на вопрос или разрешение | Поздний сигнал не наблюдался; точное время ответа на вопрос не измерялось |
| Два ребёнка, один с открытым вопросом | Вопрос доставлен; преждевременного завершения нет; после ответа и завершения семьи один итоговый сигнал |
| Прерывание текущего исполнения | Звук и баннер после остановки не наблюдались |
| Новый запуск до отправки предыдущего завершения | Один вызов notifier через 2002,984 мс после последнего завершения; вызова на старом дедлайне нет |

Последняя строка проверена с временной трассировкой настоящего модуля. Она подтверждает время вызова notifier, но не время появления баннера macOS. Отдельное наблюдение одного баннера не устанавливает точную задержку его доставки

## Отложенные проверки

В текущую приёмку MVP не входят следующие физические проверки; их нельзя считать пройденными:

- Запрос внука и ошибка потомка
- Прерывание поддерева
- Перезагрузка TUI с ожидающими таймерами
- Повторная доставка событий транспортом и несколько TUI на общей сессии
- Полная проверка времени физической доставки при отмене ожидающего завершения

Для следующего прогона фиксируйте версию OpenCode, сценарий, активное приложение и фактический результат. Сигналы разных TUI должны быть различимы. Успешный ответ SDK или завершение нативного процесса не доказывают показ баннера

## Ограничения реализации

- После reload открытые запросы и история дедупликации не восстанавливаются
- Поток событий OpenCode 2.2.5 не восстанавливает события, пропущенные при отключении. Восстановление метаданных сессий может задержать или привести к пропуску завершения
- Дедупликация действует внутри экземпляра плагина, не между несколькими TUI
- Фокус macOS определяется для всего приложения; окна и вкладки отдельно не различаются
- Уже принятое SDK или macOS уведомление отозвать нельзя

Свойства транспорта описаны в исходниках OpenCode 2.2.5: [подписка на события](https://github.com/anomalyco/opencode/blob/v2.2.5/packages/core/src/bus.ts), [поток сервера](https://github.com/anomalyco/opencode/blob/v2.2.5/packages/server/src/event-feed.ts), [подключение клиента](https://github.com/anomalyco/opencode/blob/v2.2.5/packages/client/src/solid/connection.ts)

## Зависимости

Предыдущий аудит зафиксировал предупреждения moderate в транзитивных `glob` и `minimatch`, без high/critical. Это не текущий результат аудита: перед выпуском выполняйте `npm audit --ignore-scripts`

- [glob: обход отмены AbortSignal](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4)
- [minimatch: отказ в обслуживании](https://github.com/advisories/GHSA-g3hv-75wg-m249)

Достижимость этих веток из публичного TUI-входа SDK не установлена. Это не основание считать весь граф зависимостей безопасным
