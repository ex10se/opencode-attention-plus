# Security

## Supported versions

Security fixes target only the current experimental 0.1.x series.
The current version is 0.1.0; verified compatibility is OpenCode 2.2.5.
No fixed response or fix delivery times are guaranteed.

## Reporting a vulnerability

Report vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/ex10se/opencode-attention-plus/security/advisories/new).
Do not post exploit details in public issues.
If the private form is unavailable, do not move those details to a public discussion.

Include the following in your private report:
- Plugin and OpenCode versions, and operating system
- Reproduction steps and a minimal example
- Potential impact

Remove tokens, passwords, personal data, and other secrets from examples and logs before sending them.
Report ordinary bugs without security implications in [public issues](https://github.com/ex10se/opencode-attention-plus/issues).
